    05 · Process

    How I build.

    The same four steps show up in nearly everything I've shipped.

    1. 01

      Ground it.

      Hybrid retrieval with BM25, dense vectors and a reranker, so the model reads real context instead of guessing.

      query → top-k → rerank
    2. 02

      Let it check itself.

      The agent grades its own context, rewrites weak queries and decides when to stop.

      relevant ✓ rewrite ↻
    3. 03

      Teach it to refuse.

      An honest "I couldn't find this" beats a confident hallucination, especially for bills, tickets and legal questions.

      ⊘ refuse
    4. 04

      Measure every decision.

      Ragas, DeepEval and Langfuse traces score each step, so I can tell which change actually helped.

      trace → score → compare
